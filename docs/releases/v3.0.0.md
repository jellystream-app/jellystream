## Jellystream 3.0 🎉

Die bisher größte Fassung: gemeinsam schauen, Profilauswahl, Kalender, Jugendschutz, Bedienung vom Sofa — und Zugangsdaten, die verschlüsselt auf der Platte liegen.

*English below.*

### Neu

- 👥 **Gemeinsam schauen (SyncPlay)** — Gruppe starten oder beitreten (Symbol oben rechts). Play, Pause und Spulen laufen bei allen gleichzeitig, wer zu spät kommt, springt mit.
- 👤 **„Wer schaut?"** — Profilauswahl beim Anmelden. Gespeicherte Konten mit einem Klick, die öffentlichen Benutzer des Servers mit Profilbild, Konten ohne Passwort direkt.
- 📅 **Kalender** angekündigter Folgen und die Reihe **„Demnächst"** auf der Startseite.
- 🛡️ **Jugendschutz** — Administratoren setzen je Konto eine Altersgrenze (Einstellungen → Server). Der Server setzt sie durch, sie gilt also auch in jeder anderen Jellyfin-App.
- 🛋️ **Sofa-Modus** — Pfeiltasten, Fernbedienung oder Gamepad bewegen den Fokus; größere Schrift und Rahmen (Einstellungen → Darstellung). Ein Gamepad funktioniert immer.
- ⏭️ **Rückblick, Vorschau und Werbung überspringen** — zusätzlich zum Intro, mit Plugins wie Intro Skipper. Auf Wunsch automatisch (Einstellungen → Wiedergabe).
- ✅ **Trakt.tv** — Gesehenes automatisch eintragen und den Verlauf übertragen. Braucht eine eigene Trakt-Anwendung, die Einstellungen erklären wie.
- 🖱️ **Rechtsklick-Menü** auf jeder Kachel: Abspielen, Zur Serie, Favorit, Gesehen, Playlist, Download.
- 📊 **Statistik** mit den letzten 7 und 30 Tagen und meistgesehenen Serien, **Suchverlauf**, **Jahresfilter**, **Trailer**, **Vorschaubilder** beim Spulen, Lautstärke per Mausrad.

### Besser

- 🔐 **Zugangsdaten verschlüsselt** über den Schlüsselbund des Systems. Bestehende Anmeldungen bleiben gültig.
- ⌨️ Kacheln, Folgen und Musiktitel sind vollständig per Tastatur bedienbar.
- 💡 Leere Seiten sagen, wie es weitergeht, statt nur „nichts gefunden".
- 🎞️ Die Untertitel-Vorschau zeigt Schrift, Umrandung und Höhe so, wie sie im Film erscheinen.
- 🧩 Die Plugin-Liste unterscheidet ehrlich: von Jellystream genutzt / wirkt auf dem Server / nicht nutzbar.
- 🇮🇹 Italienisch ist auswählbar.

### Behoben

- Medientasten der Tastatur blockierten Spotify & Co., auch wenn Jellystream gar nichts abspielte.
- Die Schrift Inter wurde nie geladen; sie ist jetzt mitgeliefert, ohne Anfrage an Google.
- Tray-Menü auf Deutsch fest verdrahtet und unter Linux ohne Symbol.

## Jellystream 3.0 🎉 (English)

### New
- 👥 **Watch together (SyncPlay)** — start or join a group; play, pause and seek happen for everyone at once.
- 👤 **"Who's watching?"** profile picker on the sign-in screen.
- 📅 **Calendar** of upcoming episodes and a **"Coming up"** row on the home screen.
- 🛡️ **Parental controls** — administrators set a per-account age limit, enforced by the server.
- 🛋️ **Couch mode** — arrow keys, remote or gamepad; bigger text and focus rings.
- ⏭️ **Skip recaps, previews and ads**, optionally automatically (needs a plugin such as Intro Skipper).
- ✅ **Trakt.tv** scrobbling and history sync (with your own Trakt app).
- 🖱️ **Right-click menu** on every tile, statistics, search history, year filter, trailers, trickplay previews, mouse-wheel volume.

### Improved
- 🔐 Credentials are stored **encrypted** with the system keychain; existing sign-ins keep working.
- ⌨️ Full keyboard control for tiles, episodes and tracks; helpful empty states; honest subtitle preview and plugin list; Italian available.

### Fixed
- Media keys no longer block other apps; bundled Inter font; translated tray menu with a working icon on Linux.
