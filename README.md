## 🇬🇧 English

**Jellystream** is a lightweight, clean desktop client for your self-hosted [Jellyfin](https://jellyfin.org/) media server. No browser tabs, no middleman, no third-party accounts — connect your server and enjoy your media.

### ✨ Features

**Watching**
- 🎬 **Plays everything directly** — the server only transcodes when it really has to; the player shows why.
- ⏭️ **Skip intros, recaps, previews and ads** — with server plugins such as Intro Skipper, optionally automatic.
- 🖼️ **Trickplay previews** while scrubbing, chapters, audio and subtitle tracks, speed, picture-in-picture.
- 👥 **Watch together (SyncPlay)** — play, pause and seek in sync with friends on the same server.
- 📺 **Live TV** with what's on now.
- 🎵 **Music** with queue, synced lyrics and a mini player.

**Finding things**
- 👤 **"Who's watching?"** — pick a profile on the sign-in screen, one click for saved accounts.
- 📅 **Calendar** of upcoming episodes, and a "Coming up" row on the home screen.
- 🔎 Search with history, filters by genre, year and watched state, a statistics page.
- 🖱️ **Right-click menu** on every tile; everything works with the keyboard.
- 🛋️ **Couch mode** — arrow keys, remote or gamepad move the focus spatially.

**Your setup**
- 📥 **Offline downloads** of films, episodes and music, in the quality you choose.
- 🔐 **Credentials stored encrypted** with your operating system's keychain.
- 🛡️ **Parental controls** — administrators set an age limit per account, enforced by the server.
- ✅ **Trakt.tv** scrobbling and history sync (with your own Trakt app).
- 🎨 Themes, accent colours, custom CSS, poster or landscape tiles per library.
- 🌍 Translations, Discord presence, several servers with custom names.
- 🔄 **Automatic updates** — new versions install themselves when you close the app.

## 🇩🇪 Deutsch

**Jellystream** ist ein schlanker Desktop-Client für deinen selbst gehosteten [Jellyfin](https://jellyfin.org/)-Medienserver. Kein Browser-Tab, keine Umwege, keine Drittanbieter-Accounts — Server eintragen, anmelden, schauen.

### ✨ Funktionen

**Schauen**
- 🎬 **Spielt alles direkt ab** — der Server rechnet nur um, wenn es wirklich nötig ist; der Player sagt, warum.
- ⏭️ **Intro, Rückblick, Vorschau und Werbung überspringen** — mit Server-Plugins wie Intro Skipper, auf Wunsch automatisch.
- 🖼️ **Vorschaubilder** beim Spulen, Kapitel, Ton- und Untertitelspuren, Tempo, Bild-im-Bild.
- 👥 **Gemeinsam schauen (SyncPlay)** — Play, Pause und Spulen gleichzeitig mit anderen auf demselben Server.
- 📺 **Live-TV** mit der laufenden Sendung.
- 🎵 **Musik** mit Warteschlange, mitlaufenden Songtexten und Mini-Player.

**Finden**
- 👤 **„Wer schaut?"** — Profil auf dem Anmeldebildschirm wählen, gespeicherte Konten mit einem Klick.
- 📅 **Kalender** kommender Folgen und eine Reihe „Demnächst" auf der Startseite.
- 🔎 Suche mit Verlauf, Filter nach Genre, Jahr und Gesehen-Status, eine Statistik-Seite.
- 🖱️ **Rechtsklick-Menü** auf jeder Kachel; alles geht auch mit der Tastatur.
- 🛋️ **Sofa-Modus** — Pfeiltasten, Fernbedienung oder Gamepad bewegen den Fokus.

**Einrichten**
- 📥 **Offline-Downloads** von Filmen, Folgen und Musik in wählbarer Qualität.
- 🔐 **Zugangsdaten verschlüsselt** über den Schlüsselbund des Systems.
- 🛡️ **Jugendschutz** — Administratoren setzen je Konto eine Altersgrenze, die der Server durchsetzt.
- ✅ **Trakt.tv** — Gesehenes eintragen und Verlauf abgleichen (mit eigener Trakt-App).
- 🎨 Themes, Akzentfarben, eigenes CSS, Hoch- oder Querformat je Bibliothek.
- 🌍 Übersetzungen, Discord-Präsenz, mehrere Server mit eigenen Namen.
- 🔄 **Automatische Updates** — neue Fassungen spielen sich beim Schließen der App ein.
